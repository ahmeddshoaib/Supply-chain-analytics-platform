# Supply Chain Analytics Platform

## Overview

This project demonstrates an end-to-end supply chain analytics workflow covering procurement, inventory management, logistics performance, and demand forecasting.

The objective is to showcase how data analytics can support operational decision-making in a manufacturing-style supply chain environment.

## Business Questions

### Procurement
- Which suppliers perform best?
- Which suppliers create the most delays?
- Which suppliers contribute the highest procurement spend?

### Inventory
- Which products are at risk of stockout?
- Which products are overstocked?
- Which products generate the highest inventory value?

### Logistics
- What is the on-time delivery rate?
- Which shipment routes experience the most delays?

### Demand Forecasting
- What demand should be expected in future periods?
- Which products require inventory replenishment planning?
